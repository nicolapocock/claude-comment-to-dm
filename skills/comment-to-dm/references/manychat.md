# Building it in ManyChat

ManyChat is set up in its dashboard (app.manychat.com). If you can control the user's browser and they've said you can, build it as a draft. Otherwise walk them through these steps one at a time, with the copy ready to paste.

## Before you start
- The Instagram account must be a professional account (business or creator), connected to ManyChat.
- Check the dashboard for a contact-limit banner. If the plan is full, new commenters won't get anything.

## Steps
1. On the ManyChat home screen, pick the quick automation **Auto-DM links from comments**.
2. **When someone comments on:**
   - "next post or reel" if the post isn't up yet
   - "a specific post or reel" if it's already live
3. **Comment has the word:** the keyword, exactly as it's said in the video and caption.
4. **Reply to their comments under the post:** on, with the public reply and its variations.
5. **Opening DM:** short, its only job is the tap. For example: "you commented GUIDE, tap below and i'll send it straight over". Button: "send it over".
6. **Ask to follow** (optional): turn it on and paste the follow message. The button label is fixed by ManyChat.
7. **Ask for email** (optional): in the quick builder, the email step comes BEFORE the link, not after. Put it after the link in the full Flow Builder instead, if they'd rather.
8. **The link DM:** the DM text, plus a link button to the freebie.
9. Save it as a draft. The user reads every message in the preview, tests it from a second account, then clicks **Go Live** themselves.

## Gotchas
- **Typing drops letters.** When typing into ManyChat's message fields with browser automation, type in short chunks with a pause between them, then zoom in and check the text. If a letter is missing, clear the whole field and retype it. Don't try to patch one letter.
- **Contact limits.** Plans cap contacts. When the cap is hit, new commenters silently get nothing. Old contacts with no email can be deleted to make room, but only with the user's OK.
- **Emails stay in ManyChat** until they're exported or connected to an email tool.
