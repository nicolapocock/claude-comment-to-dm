# Building it in ManyChat

You build this yourself in the browser (the desktop app's built-in browser, or the Claude in Chrome extension), in the user's logged-in ManyChat at app.manychat.com. The user doesn't click anything until Go Live.

## Before you start
1. Open app.manychat.com. If it shows a login page, ask the user to log in themselves in that browser, then carry on. Never type their password.
2. Check the dashboard for a contact-limit banner ("new contacts aren't getting automations"). If it's there, stop and tell them. New commenters won't get anything until there's room.
3. The Instagram account must be a professional account (business or creator), connected to ManyChat.

## Build it
1. On the home screen, pick the quick automation **Auto-DM links from comments**.
2. **When someone comments on:**
   - "next post or reel" if the post isn't up yet
   - "a specific post or reel" if it's already live (pick it from the grid)
3. **Comment has the word:** the keyword, exactly as approved. Add the variants too.
4. **Reply to their comments under the post:** on. Paste the public reply and its variations.
5. **Opening DM:** short, its only job is the tap, e.g. "you commented GUIDE, tap below and i'll send it straight over". Button: "send it over".
6. **Ask to follow** (if they want it): turn it on and paste the follow message. The button label is fixed by ManyChat.
7. **Ask for email** (if they want it): in the quick builder, the email step comes BEFORE the link. If they'd rather it came after, say so, and offer to build it in the full Flow Builder instead.
8. **The link DM:** paste the DM text and add a link button to the freebie.
9. **Save it. Don't press Go Live** unless the user has told you to for this automation.
10. Take a screenshot of the finished preview and show it to them with the test checklist.

## How to type into ManyChat
- **Its message fields drop letters under fast typing** ("claude" becomes "claud"). Type in short chunks of about 25 to 30 characters, with a pause of about a second between them.
- After each field, zoom in on it and check the text, emoji included.
- If anything is wrong, select all in that field, delete it and retype the whole thing. Don't try to patch one letter, it garbles the text.
- Menus can close before a click lands. Open the menu, take a screenshot, then click.

## If you get stuck
If you can't get past a step (a popup you can't close, a page that won't load, a permission prompt), say what you see. Then give the user click-by-click steps for the rest, with the copy ready to paste.
